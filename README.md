## Executar e editar

`npm install` e `npm run dev`. Acesso: http://localhost:3009.

- `npm run build`: compila e exporta o site estático em `out/`.
- `npm run typecheck`: verifica TypeScript.
- `npm run assets`: gera derivados otimizados, preservando os originais.
- `app/content.ts`: canais oficiais e textos de atendimento.
- `app/page.tsx`: seções e conteúdo institucional.
- `app/components.tsx`: menu móvel, marca e movimento discreto.
- `app/globals.css`: identidade e responsividade.
- `materials/originals/`: fontes visuais preservadas.
- `public/images/`: imagens usadas pelo site.
- `docs/fontes-e-direcao.md`: pesquisa, justificativas, imagens e pendências.
- `STATUS.md`: estado técnico e próxima ação.

Next.js 16.2.6, React 19.2.6, TypeScript. Exportação estática, sem banco, agenda, formulário ou rastreadores. Fontes Manrope e DM Serif Display são hospedadas localmente pelo build do Next. Metadados `noindex` enquanto demonstração.

## Direção específica

Verde oliva, creme e caramelo extraídos visualmente das publicações reais da BEMVI. A marca original aparece com proporções preservadas, em adaptação monocromática. A frase oficial “Se cuidar para viver bem” organiza a abertura. A moldura e o contorno do retrato dialogam com as curvas do símbolo da marca. Os atendimentos são apresentados em linhas com detalhes expansíveis, sem uma sequência de cartões repetidos.

O retrato da Adriana deriva do material oficial e recebeu limpeza de fundo/textos com a ferramenta integrada de imagens. Não é um retrato de banco nem uma profissional fictícia; o tratamento ainda requer aprovação da retratada. O original está preservado para comparação. Não foram utilizados pacientes identificáveis.
